# WPF 리팩토링 가이드라인
- 런타임: .NET 8 (C# 12 / WPF)
- 기본 패턴: MVVM 준수 (CommunityToolkit.Mvvm 활용)

# 토큰 절약 작업 수칙 (엄수)
1. 전체 코드를 요구하지 않는 한, 수정한 메서드 및 변경된 XAML 블록만 집중 출력할 것.(단위치는 정확하게 전달해줘야함 수정해야할 부분)
2. 디버깅 시 파일을 무차별로 재조회하지 말고, `dotnet build` 터미널 출력 에러 라인만 타겟팅하여 수정할 것.
3. 관련 없는 다른 View나 ViewModel 파일은 사용자 요청 없이 임의로 열어보지 말 것.
4. 한국어로 답변 해야할 것
