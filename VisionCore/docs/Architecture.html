④ 문제 생기면 여기부터

🔌 연결 안 됨 / 느림 / 끊김
  • CvsInSight.Connect — 단계별 시간 로그(ConnectTimings) 있음
  • SensorSessionViewModel.ConnectAsync
📭 결과가 안 들어옴
  • ResultsChanged 발생 여부
  • GetLatestResult
🖼 그래픽 위치/크기/글자 이상
  • GraphicsHelper (DrawText)
  • config.ini [Display] GraphicsTextScale
✏ 셀 편집 이상
  • CvsSpreadsheet.Editor.cs
  • 키 입력: ProcessCmdKey
🔍 툴 목록이 비었거나 틀림
  • JobToolScanner (참조 추적)
  • 템플릿 D열 블록 시작행 확인
📋 파라미터 이름/옵션 틀림
  • Resources/ToolCatalog.json
  • 손으로 고치지 말 것 → Tools/ToolCatalogGen으로 재생성
🇰🇷 한글 설명/이름
  • Resources/ToolDesc.ko.json (상세)
  • Resources/ToolEasy.ko.json (쉬운 이름)
🎯 캘리브레이션/원점 셀 못 찾음
  • AlignTemplate (AlignLayout.Detect)
  • 템플릿 라벨 글자 바뀌었는지
♻ 잡 바꿨는데 옛 화면 남음
  • RefreshAfterJobLoadAsync
  • InSightBehavior
⚙ 설정 저장 안 됨
  • ConfigModel + ini.cs

⑤ 주의사항

  • 커밋 안 된 작업 많음 — JobEditor, ToolSetup, Overlay 등 최근 작업 전부 미커밋. 날아가면 복구 불가.
  • 빌드 — 실제는 net48 / C# 7.3. dotnet build 안 됨 → VS MSBuild 사용. (CLAUDE.md의 ".NET 8"은 틀림)
  • MVVM — CommunityToolkit 아님. 자체 RelayCommand / ViewModelBase.
  • 실센서 미검증 — 오버레이, 캘리브레이션, 원형 ROI, 버튼 누르기, 잡 리로드. 문제 시 1순위 의심.
  • 테스트 코드 없음 — 수정 후 실기 확인 필수.
  • ToolSetupViewModel 비대 (1275줄) — 손볼 일 많아지면 탭별 분리 권장.
